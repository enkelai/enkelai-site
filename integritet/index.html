Integritet

Webbplatsen laddar inget externt, använder inga kakor, ingen spårning och ingen besöksstatistik. Sidorna driftas av GitHub Pages, som av tekniska skäl kan logga uppgifter som IP-adress. Om du mejlar mig sparas ditt meddelande i min e-post tills ärendet är avslutat, och används inte till något annat.

Om du anmäler dig till nyhetsbrevet skickas din e-postadress till Brevo (Sendinblue SAS, Frankrike), som hanterar utskicken åt mig. Se Brevos egen integritetspolicy för hur de hanterar dina uppgifter. Du kan avregistrera dig när som helst via länken i varje utskick, och uppgifterna raderas då.
